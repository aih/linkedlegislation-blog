{% comment %} Renders the `image-credits` front matter of a post or page. Each entry describes one image; `ai-model` marks an image an AI model made, and prints the version and date alongside it. Nothing is emitted when the page carries no credits. Every field is normalised to a stripped string first. Liquid counts the empty string as truthy, and Decap writes a cleared optional field as `''` rather than dropping the key, so a bare truthiness test on a field would emit a stray comma. Whitespace matters: a stripping tag (`-%}`) sits before every comma and period so none is preceded by a space, and a plain tag (`%}`) sits wherever a separating space belongs. {% endcomment %} {%- if page.image-credits.size > 0 -%} {%- assign credit_date_format = site.date_format | default: "%B %-d, %Y" -%}
